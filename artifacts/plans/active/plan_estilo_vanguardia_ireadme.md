### Tríada Conceptual del Estilo Híbrido

1. **Atractivo para el Mundo Tech (Engineering & DevEx):**
   - Badges sobrios de alto impacto (Enterprise Tier, Compliance, SLA, Architecture, Test Coverage).
   - Diagramas ASCII simétricos de alta definición reflejando planos de control y de datos.
   - Comandos deterministas reproducibles de una sola línea y validación en CI/CD.
2. **Ejecutivo Corporativo de Vanguardia (C-Level / VP Engineering / Platform Leads):**
   - Resumen ejecutivo estructurado: Tensión operativa de negocio (coste de inacción/deuda), propuesta de valor estratégico (ROI, reducción de TCO, mitigación de riesgo de deriva), y resolución arquitectónica.
   - Matriz bimodal de rendimiento: SLAs corporativos y métricas de ingeniería (p95/p99, error budget, compliance).
   - Ontología y gobernanza institucional auditable.
3. **Nomenclatura Paper para Explicar Formulación (IEEE/ACM Systems Rigor):**
   - Notación LaTeX ($\LaTeX$) rigurosa para funciones objetivo, cotas operacionales, invariantes de paridad y teoría de información.
   - Cero emojis y estética monocromática/neutra formal.
   - Referencias formales de literatura y snippet BibTeX.

## 2. Componentes de Distribución Universal en el Repositorio

Para que cualquier usuario que clone el repositorio pueda usar la skill inmediatamente en su IA preferida ("llegar e instalar"):

1. **`skills/readme/SKILL.md`**: Definición canónica de la skill universal con frontmatter YAML compatible con Antigravity, Open Code y protocolos de agentes.
2. **Instaladores Automatizados Multi-Plataforma**:
   - `scripts/install_skill.py`: Script Python con autodetección de entornos (Google Antigravity global `~/.gemini/config/skills/`, Claude Code `~/.claude/skills/`, Cursor `.cursor/rules/`, o local `.agents/skills/`).
   - `install.ps1`: Script PowerShell de 1 clic para usuarios Windows.
   - `install.sh`: Script Bash de 1 clic para usuarios Linux/macOS.
3. **Conectores Nativos para las Principales IAs**:
   - `GEMINI.md`: Reglas para Google Gemini CLI y Antigravity.
   - `AGENTS.md`: Estándar abierto universal para agentes autónomos.
   - `CLAUDE.md`: Reglas nativas para Anthropic Claude Code y Claude Desktop Projects.
   - `OPENAI.md`: System prompt y configuración para OpenAI ChatGPT Projects / Codex.
   - `.cursorrules`: Reglas de contexto instantáneo para Cursor IDE.
   - `.github/copilot-instructions.md`: Instrucciones nativas para GitHub Copilot Chat.
